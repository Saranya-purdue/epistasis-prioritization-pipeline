# FUMA SNP2GENE Analysis

This module prepares SNP lists for submission to FUMA SNP2GENE and annotates prioritized SNP-SNP interaction pairs with nearby-gene information returned by FUMA.

The workflow is split into two steps:

1. **Prepare lead SNPs** from the final SNP-pair table
2. **Annotate SNP pairs** using FUMA SNP2GENE output (`snps.txt`)

## Module structure

```text
fuma_analysis/
├── README.md
└── fuma_analysis.py
```
**Overview**

The final 3P-filtered SNP-pair table contains pairwise interactions in which each SNP is stored in a variant string format such as:

chr16:12345:rs123:A:G

From this table, the module:

- extracts all unique SNPs across snp1 and snp2
- parses chromosome, position, and rsID
- writes a lead SNP file for FUMA SNP2GENE upload
- reads the returned FUMA snps.txt file
- maps each SNP in the interaction pair to its nearestGene annotation

**Requirements**

The code uses Python with:

- numpy
- pandas

Install with:
```text
pip install numpy pandas
```
**Input format**

- Pair file - The pair file must contain at least: snp1, snp2

- It may also contain other columns such as:

  - interaction_strength
  - class
  - beta_interact_lin
  - p_interact_lin

- Variant format

  - The script expects variant strings of the form: chr:pos:rsid:ref:alt

Step 1: Prepare FUMA lead SNP input

This step extracts all unique SNPs from the pair table and writes a tab-delimited file containing: rsID, chr, pos

**How to run**
```text
python fuma_analysis.py prepare-leads \
  --pairs_csv path/to/allchr_pairs_3P_filtered.csv \
  --output_dir outputs/fuma_analysis
```
**Main output**
```text
outputs/fuma_analysis/
├── fuma_predefined_lead_snps.txt
└── prepare_leads_summary.json
```

Output file description
fuma_predefined_lead_snps.txt

Lead SNP table for FUMA SNP2GENE upload

The file is written as tab-delimited text with columns: rsID, chr, pos

Step 2: Annotate pairs with FUMA output

After submitting the lead SNP file to FUMA SNP2GENE and downloading the results, use the snps.txt file to map each SNP in the interaction pairs to its nearby gene annotation.

The script uses: rsID, nearestGene, gwasP

If duplicate rsIDs are present in the FUMA file, the script keeps the row with the smallest gwasP.

**How to run**
```text
python fuma_analysis.py annotate-pairs \
  --pairs_csv path/to/allchr_pairs_3P_filtered.csv \
  --fuma_snps_file path/to/snps.txt \
  --output_dir outputs/fuma_analysis
```

**Main output**

```text
outputs/fuma_analysis/
├── pairs_with_fuma_genes.csv
└── annotate_pairs_summary.json
```
**Output file description**

The annotated pair table includes: snp1_rsid, snp2_rsid, snp1_gene, snp2_gene

along with all original columns from the input pair table.

**Example workflow:**

1. Prepare lead SNPs for FUMA upload
python fuma_analysis.py prepare-leads \
  --pairs_csv path/to/allchr_pairs_3P_filtered.csv \
  --output_dir outputs/fuma_analysis

Upload:

outputs/fuma_analysis/fuma_predefined_lead_snps.txt

to FUMA SNP2GENE.

2. Annotate the pair file after FUMA finishes
python fuma_analysis.py annotate-pairs \
  --pairs_csv path/to/allchr_pairs_3P_filtered.csv \
  --fuma_snps_file path/to/snps.txt \
  --output_dir outputs/fuma_analysis

**Notes**
This module assumes that the SNP-pair table was already generated by the upstream 3P-rule pipeline.
The script uses nearestGene from FUMA SNP2GENE as a lightweight gene annotation for each SNP in a pair.
Only rsIDs matching the pattern ^rs\d+$ are kept by default when preparing the lead SNP file.
The module does not run FUMA itself; it prepares inputs and processes downloaded outputs.
